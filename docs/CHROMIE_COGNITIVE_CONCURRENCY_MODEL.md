# Chromie cognitive concurrency model

## Invariant

Chromie has one authoritative Cognitive Core and three concurrent semantic
coordination lanes. The lanes are not independent minds and do not define
container ownership.

```text
One Cognitive Core
        |
        +-- Social-Attention Proposal Lane
        +-- Speaking Lane
        +-- Activity Lane
```

```text
one mind
multiple concurrent semantic lanes
one Chromie Interaction Orchestrator
one Soridormi platform-execution boundary
```

## Cognitive Core

The Cognitive Core owns user meaning, Goal Association, Goal lifecycle,
planning, personality, model-authored communication, vocal mode, and requested
temporal relationships. It accepts, rejects, combines, or suppresses social-
attention proposals and selects exact platform-neutral capabilities.

Execution components do not reinterpret what the user meant.

## Social-Attention Proposal Lane

This lane observes interaction state and submits bounded proposals such as:

```text
maintain attention on person_1
natural blink is appropriate
brief acknowledgement is appropriate
avoid speaking while the user is still talking
suspend proactive expression during physical recovery
```

It must not author speech meaning, create or own Goals, select final
capabilities, authorize actions, operate devices, or override execution safety.

Its proposals can affect three destinations:

```text
communication proposal or suppression -> Speaking coordination
physical-expression proposal           -> authoritative planner -> Activity
attention/context update                -> Cognitive Core
```

## Speaking Lane

The Speaking lane represents communication generated by Chromie. It owns the
semantic vocal outcome and a typed Vocal Plan, including at least ordinary
speech, expressive speech, recitation, singing, humming, and nonverbal
vocalization.

Response authorship, personality, and mode choice remain in Chromie. Under the
approved target, Soridormi executes the Vocal Plan through a declared provider
and returns streaming, start, interruption, delivery, completion, or failure
evidence. A provider may support only a subset of modes.

Singing remains Speaking even when it overlaps body Activity. Playing an
existing song is media Activity, not singing. Expressive TTS is not proof that a
provider can perform singing.

## Activity Lane

The Activity lane represents exact capability work selected for Goals. It may
include body action, media playback, information retrieval, memory, device
control, and future capability providers. Platform-facing body, media, sensor,
and device execution converges behind Soridormi; platform-independent
information or memory providers may remain peers.

The Activity lane does not own Goal meaning and does not silently select a
replacement capability after refusal.

## Two coordinators, one semantic authority

The **Chromie Interaction Orchestrator** operates above the lanes. It owns turn
and session lifecycle, Gateway/Core dispatch, confirmation, user-level
cancellation scope, immutable authorization, and evidence correlation. It
expresses whether members should be sequential or concurrent but does not own
platform scheduling.

The **Soridormi Execution Coordinator** operates below the immutable execution
envelope. It owns provider-local preparation, resources, timing, start,
cancellation, recovery, and normalized per-member evidence for body, vocal,
media, and platform-facing work. It may reject infeasible work but cannot change
Goal meaning, content, vocal mode, or confirmation.

A coordination group uses one identity across both boundaries. Chromie authors
the semantic relationship; Soridormi proves how the current platform actually
executed it.

## Cancellation authority

Chromie owns user-level cancellation meaning:

- stop or replace audible output;
- cancel or replace a Goal;
- stop body motion;
- cancel the current interaction;
- request global emergency handling.

Soridormi owns execution of the authorized scope and immediate platform safety:

- stop a vocal or media stream;
- cancel provider-local members;
- fall, collision, balance, actuator, or device safety response;
- emergency stop, safe hold, and recovery.

Acoustic speech start may pause or duck output without cancelling Goals, but the
semantic scope is resolved later by Chromie. Soridormi does not wait for
semantic approval before applying mandatory physical or hardware safety.

## Repository ownership

This Soridormi repository defines and tests the execution-runtime, platform-
provider, resource, safety, and evidence contracts. The companion Chromie
repository implements the Cognitive Core, three semantic lanes, Interaction
Orchestrator, Goal reconciliation, and user-facing meaning without creating a
second cognitive agent inside Soridormi.
